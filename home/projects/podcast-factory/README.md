# Podcast Factory

Podcast Factory is a content production workflow for planning, drafting,
reviewing, and publishing podcast episodes. It keeps research, episode
structure, audio assets, and publishing metadata connected from the first idea
to the final release.

## Workflow

- capture and refine episode ideas;
- organize research into a reusable brief;
- generate a draft with explicit editorial checkpoints;
- prepare show notes, titles, and publishing metadata;
- preserve the source material and revision history.

```mermaid
flowchart LR
  Idea[Episode idea] --> Brief[Research brief]
  Brief --> Draft[Episode draft]
  Draft --> Review[Editorial review]
  Review --> Package[Show notes and assets]
  Package --> Publish[Publish]
```

The goal is a calm, inspectable pipeline that makes creative work easier to
repeat without flattening the editorial decisions that give each episode its
voice.
